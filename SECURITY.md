# Sicurezza

Routally è in fase pre-release e non dispone ancora di versioni pubbliche supportate.

Non segnalare vulnerabilità tramite issue, discussion o altri canali pubblici. Usa
**Security → Report a vulnerability** su GitHub, che apre una segnalazione privata.
L'indirizzo email dedicato verrà aggiunto dopo la chiusura di `DG-DOMAIN`.

Non includere credenziali, dati personali o dati Routally reali nelle segnalazioni.
